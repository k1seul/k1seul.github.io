> **개통 후 신청을 받을 예정입니다.** 아래는 적용할 계정 등록 절차이며 아직 등록이 완료된 상태를 뜻하지 않습니다.

## 신청 전에 확인할 것

GSDS 계정으로 **GSDS 로그인 환경**에 접속하여 실행합니다. LAAL의 `master`에서 실행한 결과와 혼동하지 않도록 해 주세요.

```bash
hostname
whoami
id
```

`id`에 표시되는 UID는 사용자 번호, GID와 groups는 그룹 번호입니다. 스토리지에서도 같은 번호를 사용해야 파일 소유권과 공유 폴더 권한을 올바르게 확인할 수 있습니다.

## 관리자에게 보낼 정보

김한슬에게 DM으로 아래를 보내 주세요.

```text
학교 이메일:
GSDS 사용자 이름:
LAAL 사용자 이름(있는 경우):
GSDS에서 실행한 id 결과:
필요한 용량과 용도:
공유할 프로젝트 또는 구성원(있는 경우):
예상 사용 기간:
```

비밀번호와 SSH 개인키는 보내지 않습니다. 계정 정보는 공개 게시글 대신 비공개 메시지로 전달해 주세요.

## 계정은 어떻게 추가되나요?

1. 관리자가 GSDS 계정과 연구실 그룹 정보를 확인합니다.
2. 스토리지에 **GSDS와 동일한 사용자 이름·UID/GID와 필요한 보조 그룹**으로 사용자를 등록합니다. 같은 번호의 기존 계정이 있으면 충돌 여부를 먼저 확인합니다.
3. 개인 폴더 또는 프로젝트 공유 폴더의 소유권·접근 권한·용량 제한을 설정합니다.
4. 등록 완료 후 사용할 경로와 배정 용량을 전달합니다.

이 절차는 **기존 GSDS 계정에 대응하는 스토리지 사용자를 등록하는 것**입니다. GSDS 계정을 새로 발급하거나 LAAL·GSDS의 비밀번호를 동기화하는 절차가 아닙니다. 이용자는 GSDS 계산 환경에서 저장 경로를 사용하며, 스토리지 서버에 별도로 SSH 접속할 필요는 없습니다.

## 등록이 끝났는지 어떻게 알 수 있나요?

관리자가 등록 완료와 경로를 안내한 뒤 [내 계정과 권한 확인](/ko/server/gsds-operations)을 진행합니다. 기존 홈 경로나 실험 출력 경로는 안내 전에 바꾸지 마세요.
