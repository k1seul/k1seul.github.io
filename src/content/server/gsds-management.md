## Who does what

The storage server belongs to LAAL, and **LAAL handles most of the work and cost**.

| LAAL handles | GSDS provides |
| --- | --- |
| buying the hardware and its costs | rack space in the GSDS server room |
| setup, accounts, and quotas | power and cooling |
| monitoring, disk replacement, and repairs | network connection |
| user support | account (UID) information so accounts match GSDS |

## Operations (planned)

- **Maintenance:** done together with the monthly LAAL maintenance in the first week of each month. Any physical work in the GSDS server room is coordinated with the GSDS admins.
- **Monitoring:** the admins watch capacity and disk health, and notify users before any quota change or cleanup.
- **Problems:** DM Hanseul Kim, or Minsoo Jo if it's urgent, with the details listed in [Reporting a problem](/server/administration#reporting-a-problem).
